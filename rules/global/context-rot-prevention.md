# Context Rot 방지

## 룰 파일 크기
`rules/` 합산 10,000자, 프로젝트 CLAUDE.md는 별도 10,000자. 넘으면 다이어트 제안.
세션 시작 시 확인 X, 룰 수정할 때만 체크.
- 측정은 **문자**다. `wc -c`는 바이트라 한글이 3배로 뜬다 — `python3 -c "import sys;print(len(open(sys.argv[1],encoding='utf-8').read()))"`.
- **자수보다 충돌이 먼저다.** 룰을 더할 땐 같은 상황을 다루는 기존 조항을 먼저 찾아 충돌·중복을 확인한다. 충돌 해소는 자수를 늘려서(예외 명시) 하는 게 맞다.

## MCP 서버
안 쓰는 MCP는 disabled. 도구 스키마는 deferred라 이름만 상주한다 — 토큰보다 연결·인증 관리 부담이 실제 비용.

## 문서 분산 금지
같은 정보 여러 파일에 흩지 마라. 한 정보 = 한 파일, 다른 곳은 링크/요약만.
한 곳만 고치고 다른 곳 stale → 일관성 깨짐.
