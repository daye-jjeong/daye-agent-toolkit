# Background Automator

화면의 한국어 문구와 버튼 상태를 확인하고, 사용자가 3초 동안 입력하지 않았을 때만 대상 게임 창을 잠시 앞으로 가져와 클릭한 뒤 원래 앱과 마우스 위치를 복원하는 로컬 메뉴 막대 앱입니다. 화면이나 입력 데이터는 외부로 업로드하지 않습니다.

## 빌드와 실행

macOS 14 이상에서 다음 명령으로 로컬 앱 번들을 만듭니다.

```bash
cd apps/background-automator
bash scripts/build-app.sh
open "dist/Background Automator.app"
```

산출물은 `dist/Background Automator.app`입니다. 앱의 로컬 번들 ID는 게임과 무관한 `com.dayejeong.background-automator`입니다. `/Applications`에는 자동으로 설치하지 않습니다.

## 처음 설정

1. 메뉴 막대의 커서 아이콘을 엽니다.
2. 대상 게임 앱의 **번들 ID**와 자동화할 창의 **정확한 제목**을 입력합니다. 같은 제목의 창이 둘 이상이면 시작하지 않습니다.
3. macOS 시스템 설정의 개인정보 보호 및 보안에서 이 앱에 **화면 기록**, **손쉬운 사용**, **입력 모니터링** 권한을 허용합니다. 권한 변경 뒤 앱 재실행이 필요할 수 있습니다.
4. 게임 창을 화면에 보이는 상태로 두고 최소화하지 않습니다. 가로 화면과 모바일 세로 화면을 지원합니다.
5. 메뉴에서 `시작`을 누르고, 멈출 때는 `중지`를 누릅니다.

자동화는 사용자의 키보드·마우스 입력이 3초 동안 없을 때만 동작합니다. 클릭할 때 대상 창이 잠깐 앞으로 나오며, 동작 후 원래 앱과 마우스 위치를 복원합니다. 사용자가 중간 절차를 직접 진행하면 다음 화면을 다시 인식해 이어갑니다.

현재 `도전` 버튼의 회색 상태와 `입장하기` 활성 상태를 구분하는 화면 색상 기준은 초기값입니다. 실제 게임 테마·밝기·그래픽 설정에 맞춘 라이브 보정 전에는 자동 클릭을 지켜보며 확인해야 합니다.

`진단 폴더 열기`는 현재 로컬 폴더만 엽니다. 상세 로그 수집과 내보내기는 후속 작업입니다.
