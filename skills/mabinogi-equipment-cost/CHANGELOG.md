# Changelog

## 0.2.0 (2026-08-15)
- 여러 사람이 쓸 수 있게 됐다. 재고를 서버 DB에서 **브라우저 쿠키**(`mabi_inv`)로 옮겼다 — 전에는 한 서버를 쓰면 전원이 한 재고를 공유했다.
- `serve.py --public`: `0.0.0.0` 바인딩 + 새로고침 버튼 끔 + 서버가 직접 주기 수집. 방문자마다 버튼을 누르면 원본 API 요청이 서버 IP 하나로 몰린다.
- 시세 수집 주기 600초 → **180초**. 원본 기준 시각이 1분 만에도 바뀐 실측을 확인했다(10분 주기는 그 사이를 흘렸다).
- `collect.py seed`: 레시피·아이템만 담은 배포용 DB(실측 88KB). 상세 API 쿼터 때문에 새 환경에서 레시피를 다시 받으면 몇 시간이 든다.
- `deploy/Dockerfile` + [배포 문서](references/deploy.md).
- 예전에 DB에 저장한 재고는 로컬 첫 방문 때 그 브라우저로 한 번 넘어가고 테이블이 사라진다.
- **신선도를 "받은 시각"으로 잰다.** 전에는 원본 스냅샷 시각(`as_of`)만 봐서, 원본이 21분간 같은 값을 주는 동안 멀쩡한 수집기를 "멈춘 것 같다"고 경고했다(실측). 이제 `collect_log`에 수집 시각을 남기고, 원본이 늦는 건 경고 대신 "원본이 그 뒤로 새 값을 안 준다"로 적는다.
- 수집 실패는 이유와 연속 횟수를 상단 띠에 띄운다 — 전에는 서버 콘솔에만 찍혀 방문자가 볼 수 없었다.
- 시각을 `<time datetime>`으로 내보내 브라우저가 로컬 시각으로 바꾼다. `07:46 UTC` → 한국에서는 `16:46`.

## 0.1.0 (2026-08-15)
- 최초 릴리스: 잔영·해연 장비 76종의 거래소 최저가 · 일반 제작 · 레시피 제작 · 잔영×N 비교 페이지.
- 수집기는 시세(쿼터 없음)와 레시피(쿼터 있음, 이어받기)를 분리해 돈다.
- 원가 계산은 `scripts/cost.py`의 순수 함수 한 곳에 모았다. 픽스처는 2026-08-14T16:17Z 실측 스냅샷.
- 마도저항 수치 계산은 범위 밖 — 부위별 수치표가 없고 API에도 감정 옵션 수치가 없다.
