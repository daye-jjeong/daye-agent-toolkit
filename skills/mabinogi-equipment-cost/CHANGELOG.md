# Changelog

## 0.3.0 (2026-08-19)
- **재료를 누르면 30일 범위 띠 차트가 그 줄 아래에 펼쳐진다.** 고가~저가가 옅은 면, 종가가 선. 최저·최고였던 날짜와 값에 라벨이 붙고 현재가가 수평선으로 지나간다. 실측 망령의 영혼석: `8/9 최저 50` · `8/17 최고 139` · `지금 105`.
- 띠는 **이어 붙인 면**이다. 하루마다 사각형을 세우는 안과 둘 다 그려 비교했다 — 막대는 30개를 하나씩 읽게 하고 종가선을 가리는데, 면은 폭의 변화가 형태로 들어온다(8/16 이후 값이 오른 게 아니라 변동이 커진 것이 막대에서는 안 보였다).
- **차트에 마우스를 올리면 그날 값이 뜬다** — 날짜·요일 + 시가·고가·저가·종가. 축과 라벨만으로는 최저·최고였던 이틀 말고 나머지 28일을 못 읽는다. 마우스 x에서 가장 가까운 날을 잡으므로 점(반지름 3픽셀)에 맞출 필요가 없다.
- 툴팁은 **데스크톱만**(`hover: hover`). 폰에서는 차트를 옆으로 밀어 봐야 해서 탭이 스크롤 제스처와 부딪힌다.
- 툴팁에 **매물 수는 안 넣었다.** "거래량"으로 읽히는데 원본에 체결·거래량 필드가 아예 없다 — 매물 수가 줄어도 팔린 건지 판매자가 내린 건지 구분 못 한다.
- 가로는 **날짜에 비례**한다. 순서대로 놓으면 원본에 없는 날이 있었던 것처럼 보인다 — 18종 전부 8/12(KST)이 빠져 있다. 그 자리에서 면과 선을 끊는다.
- 펼침은 **이름과 스파크라인**에만 건다. 줄 전체를 누르게 하면 수량을 넣으려다 차트가 열린다.
- 정통 캔들(몸통+심지)은 쓰지 않는다. 우리 값은 "그날 거래소 최저가"의 OHLC라 몸통 색이 매수·매도 압력을 뜻하지 않는다.
- **작은 줄이 2주 최저·최고를 숫자로 낸다.** 스파크라인을 72×18에서 120×26으로 키우고 양 끝에 범위 값을 붙였다 — 전에는 모양만 있어 "2주 전엔 얼마였나"에 답하지 못했다. 대신 `오늘 89~123`은 뺐다(펼침 차트의 마지막 띠가 그 값이다).
- 값이 안 움직인 재료(백금강괴·특급 목재 등)는 같은 숫자를 세 번 적지 않는다. 차트도 최고·최저 라벨을 빼고 눈금 하나만 둔다 — 눈금 셋을 그으면 ±1만큼 움직인 것처럼 보인다.
- 재고 입력칸 그리드가 칸당 232 → **300픽셀**. 1,000픽셀 창에서 3열이 2열이 된다. 선과 범위 값을 한 줄에 두려면 그만큼 필요하다.
- **날짜를 KST로 적는다.** 일봉 버킷이 21:00Z(=KST 06:00)에 시작해서, UTC 날짜를 그대로 쓰면 오늘 캔들이 늘 어제로 찍혀 "하루 낡음"이 상시 뜬다.
- 캔들이 하루 이상 낡으면 차트에 기준일을 적는다. 상단 노란 띠는 띄우지 않는다 — 일봉은 곁다리라 그 실패로 전체를 경고 상태로 만들지 않는다.
- 30일 자르기 · 최저/최고 지점 · 세로 범위 · 좌표 변환은 전부 `trend.py`의 `material_chart` 순수 함수. `serve.py`는 SVG 문자열만 만든다. 현재가가 30일 범위를 벗어나면 **범위를 넓힌다** — 잘라내면 "범위 안에 있다"는 거짓 인상을 준다.
- 차트 SVG는 560~900픽셀 사이에서만 늘고 준다. 끝까지 줄이면 좁은 화면에서 날짜가 4~5픽셀이 되고, 끝까지 늘리면 넓은 화면에서 글자만 커진다.

## 0.2.0 (2026-08-15)
- 여러 사람이 쓸 수 있게 됐다. 재고를 서버 DB에서 **브라우저 쿠키**(`mabi_inv`)로 옮겼다 — 전에는 한 서버를 쓰면 전원이 한 재고를 공유했다.
- `serve.py --public`: `0.0.0.0` 바인딩 + 새로고침 버튼 끔 + 서버가 직접 주기 수집. 방문자마다 버튼을 누르면 원본 API 요청이 서버 IP 하나로 몰린다.
- 시세 수집 주기 600초 → **180초**. 원본 기준 시각이 1분 만에도 바뀐 실측을 확인했다(10분 주기는 그 사이를 흘렸다).
- `collect.py seed`: 레시피·아이템만 담은 배포용 DB(실측 88KB). 상세 API 쿼터 때문에 새 환경에서 레시피를 다시 받으면 몇 시간이 든다.
- `deploy/Dockerfile` + [배포 문서](references/deploy.md).
- 예전에 DB에 저장한 재고는 로컬 첫 방문 때 그 브라우저로 한 번 넘어가고 테이블이 사라진다.
- **신선도를 "받은 시각"으로 잰다.** 전에는 원본 스냅샷 시각(`as_of`)만 봐서, 원본이 21분간 같은 값을 주는 동안 멀쩡한 수집기를 "멈춘 것 같다"고 경고했다(실측). 이제 `collect_log`에 수집 시각을 남기고, 원본이 늦는 건 경고 대신 "원본이 그 뒤로 새 값을 안 준다"로 적는다.
- 수집 실패는 이유와 연속 횟수를 상단 띠에 띄운다 — 전에는 서버 콘솔에만 찍혀 방문자가 볼 수 없었다.
- 시각을 `<time datetime>`으로 내보내 브라우저가 로컬 시각으로 바꾼다. `07:46 UTC` → 한국에서는 `16:46`.
